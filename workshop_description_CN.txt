让 Viewpoint 的光照与环境效果融入《僵尸毁灭工程》的原版等距视角。

在保留熟悉的操作方式与画面布局的同时，使用动态阴影、色彩画风、水面、草地、积雪与足迹；也可以开启 3D 模型和视角旋转，获得更多观察角度。

[h2]主要功能[/h2]
[list]
[*]动态阴影：支持太阳、月亮、室内灯光、手电筒与车灯投影，以及物体之间的阴影相互作用。
[*]轻量化动态阴影：仅保留角色、僵尸、动物、汽车、树木、房屋，以及通过“放置”摆出的背包物品投影；其他物体仍可接收阴影。
[*]色彩画风：在原版视角使用 Viewpoint 的画风，并调整强度、曝光、饱和度和对比度。
[*]环境效果：原版视角也可独立开启 Viewpoint 水面、草地、积雪与足迹。积雪支持厚度、踩踏痕迹和物体埋雪效果。
[*]可选 3D 模型：接入原版去顶、切墙、视野明暗和透视渐变规则，并适配门、容器、墙灯等交互。
[*]视角旋转：开启 3D 模型后，可按住鼠标中键并移动鼠标旋转视角。
[*]独立设置：各项效果可单独开关，并保留已有配置。
[/list]

[h2]依赖与使用[/h2]
需要安装并启用：
[list]
[*]Viewpoint
[*]ZombieBuddy
[*]Viewpoint Isometric Plus
[/list]

启用后请完全重启游戏。

按 Delete 打开 Viewpoint 菜单：
[list]
[*]高级 → 附加模组：启用或关闭“Viewpoint 等距增强”，查看模组信息。
[*]选项 → Viewpoint 等距增强：调整模型、视角、阴影、色彩及环境效果。
[/list]

积雪与足迹需要地图已有积雪，并将当前着色器包的 Snow 设置设为非 Off。

[h2]兼容说明[/h2]
适配 Project Zomboid 42.22.2、Viewpoint 0.1.7。
已针对 Default / Modern、Vivid、Somber、Library、True Weathers，以及 PZO、Project Reflections 进行兼容处理。具体效果取决于当前着色器包与模型资源包。

建议为 Viewpoint 安装更多兼容的模型扩展包。更完整、准确的物体模型，可以让原版视角下的动态阴影轮廓更贴近物体外形，提升投影效果；无需开启本模组的 3D 模型显示。

渲染功能在客户端运行；联机请按照 Viewpoint 和 ZombieBuddy 的安装要求配置。
